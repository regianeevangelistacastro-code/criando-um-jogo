
# 🏝️ A Ilha dos Cristais

Um jogo de aventura 2D desenvolvido com JavaScript e Phaser.

## 🎮 Como jogar

- Use WASD ou as setas para movimentar o personagem.
- Explore a ilha.
- Colete os 5 cristais mágicos.
- Complete sua primeira missão!

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Phaser 3

## 🚀 Como executar

Abra o arquivo index.html usando um servidor
local de desenvolvimento.
